# Security Policy

## Scope

This repository contains instructions and code templates that Claude Code uses to generate frontend code, including authentication code. Security issues worth reporting include:

- A template or instruction that produces an exploitable weakness (for example token leakage, an open redirect, or a broken refresh flow).
- Plugin or marketplace configuration that could cause unintended behavior when installed.
- Secrets or personal data committed to the repository.

Problems in your own backend, or in a third-party library, belong with those projects.

## Reporting a vulnerability

Please **don't open a public issue** for a security problem. Use GitHub's private reporting instead: open the repository's **Security** tab and choose **Report a vulnerability**. If that option isn't available, contact the maintainer through their [GitHub profile](https://github.com/Piyushverma122) and ask for a private channel.

Please include what you found, how to reproduce it, and the versions involved.

## What to expect

This is a volunteer-maintained project. We'll aim to acknowledge reports within a week, but we can't promise a fix timeline. We'll credit reporters who want credit.

## Supported versions

Only the latest release on `main` is supported.

## Reminder for users

Skills run with your agent's permissions. Review any skill before installing it, including this one.
